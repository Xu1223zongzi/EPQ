\subsection{Kernelized Correlation Filters (KCF)}
KCF is known for its high speed and relies on the properties of multi-channel correlation filters. It utilizes circulant matrices to enhance processing speed.

function alphaf = train(x, y, sigma, lambda)
	k = kernel_correlation(x, x, sigma);
	alphaf = fft2(y) ./ (fft2(k) + lambda);
end

function responses = detect(alphaf, x, z, sigma)
	k = kernel_correlation(z, x, sigma);
	responses = real(ifft2(alphaf .* fft2(k)));
end

function k = kernel_correlation(x1, x2, sigma)
	c = ifft2(sum(conj(fft2(x1)) .* fft2(x2), 3));
	d = x1(:)' * x1(:) + x2(:)' * x2(:) - 2 * c;
	k = exp(-1 / sigma^2 * abs(d) / numel(d));
end

\subsection{CSRT (Channel and Spatial Reliability Tracker)}
CSRT improves on basic correlation filters by introducing spatial reliability maps, allowing it to adapt better to irregularly shaped objects and occlusions.

\subsection{TLD (Tracking-Learning-Detection)}
TLD explicitly decomposes the long-term tracking task into tracking, learning, and detection, making it highly robust to full occlusions and objects leaving the camera view.
